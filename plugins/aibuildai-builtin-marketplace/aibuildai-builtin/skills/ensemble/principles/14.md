# Principle 14: Boosting

**Space**: Model-space / meta.

**Source**: Freund & Schapire 1997 (AdaBoost); Friedman 2001 (Gradient Boosting); scikit-learn Ensemble documentation; XGBoost / LightGBM / CatBoost.

## Definition

A **sequential** family of ensemble methods in which each new weak learner is trained to correct the errors of the cumulative ensemble so far, producing a weighted additive model.

## Mechanism

Two canonical instantiations:

- **AdaBoost** re-weights training examples each round: examples misclassified by the current ensemble get larger weights, so the next weak learner focuses on them.
- **Gradient Boosting** frames each new weak learner as a step in functional gradient descent: the next learner fits the negative gradient of a loss function with respect to the current ensemble output. This is the basis of XGBoost, LightGBM, and CatBoost.

The final prediction is a weighted sum of the weak learners' outputs, with weights determined during training by the boosting procedure itself.

## Pros

- **Reduces bias** (the opposite of bagging). Turns weak learners into a strong ensemble.
- **State-of-the-art on most tabular data.** XGBoost, LightGBM, and CatBoost dominate structured-feature benchmarks.
- Built-in feature importance and handling of mixed numerical/categorical features.

## Cons

- **Strictly sequential** — boosting rounds cannot be parallelized (though per-round tree fitting parallelizes).
- **Sensitive to label noise** because mislabeled examples get up-weighted each round and the ensemble devotes capacity to memorizing them.
- Prone to overfitting if trained for too many rounds; requires early stopping on a held-out validation set.

## When to Use

Default choice for tabular supervised learning with structured features and moderate dataset sizes. Prefer boosting over deep neural networks for tabular problems in most cases — the engineering-to-accuracy ratio is much better.

## Common Misconception

That boosting works well as an ensemble strategy for deep networks. In practice it is rarely used because the per-round retraining cost is prohibitive; each new "weak learner" would be a full DNN training run. Deep learning ensembling instead uses snapshot ensembling, SWA, simple averaging, or stacking. Some research exists on snapshot-boosting or gradient-boosted DNNs, but these are niche.

## Load-Bearing Quote

> "The core principle of AdaBoost is to fit a sequence of weak learners on repeatedly modified versions of the data."
>
> — scikit-learn Ensemble documentation
