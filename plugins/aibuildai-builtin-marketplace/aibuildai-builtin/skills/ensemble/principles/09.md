# Principle 9: Test-Time Augmentation (TTA)

**Space**: Data / pipeline.

**Source**: albumentations and ttach TTA documentation; nnU-Net, MMEngine TTA implementations.

## Definition

Apply a chosen set of **label-preserving augmentations** to each test input, run the model on each augmented copy, and aggregate the outputs (typically by mean or max). For dense prediction tasks (segmentation, detection) each augmented prediction must be **inverse-transformed** back into the original coordinate frame before aggregation; for scalar classification no inverse is needed because the output does not have spatial coordinates.

## Mechanism

A model trained with data augmentation has learned approximate invariance to the augmentation group, but the learned invariance is imperfect. By evaluating the model on several augmented views of the same test input and averaging the predictions, TTA effectively computes a Monte-Carlo approximation to the orbit-averaged prediction — a prediction that would hold under the true invariance. The augmentations chosen must correspond to task symmetries: horizontal flip for natural images, full D4 dihedral group (flip + 90° rotations) for overhead or medical imaging, small translations for robust classifiers. Transforms that violate task symmetry hurt rather than help.

## Pros

- No retraining required. Plugs into any pretrained model.
- **Complementary with every other ensemble method** — stacks multiplicatively with fold ensembling, cross-architecture ensembling, snapshot ensembling.
- Often provides a cheap uncertainty proxy: variance across augmented predictions correlates with prediction confidence.

## Cons

- Inference cost multiplies by the number of augmentations (typically 4–8, sometimes up to 16 or more).
- Diminishing returns past a small number of transforms.
- **Wrong transforms actively degrade performance**: vertical flip on natural images with a gravity prior (sky up, ground down), rotation on OCR or digit tasks, flip on tasks with a left-right directional label.

## When to Use

When inference latency is not critical and the task has a known symmetry group. Nearly universal for offline benchmark submissions on vision segmentation and classification. The TTA set should be small and validated against a held-out metric rather than guessed from intuition — a bad TTA set costs accuracy and extra latency simultaneously.

## Common Misconception

That TTA always helps. It only helps when the chosen augmentations preserve the label. A transform that the model has never seen during training, or that violates a task's directional semantics, can produce outputs that average into a worse ensemble than the single-crop baseline.

## Load-Bearing Quote

> "Test Time Augmentation (TTA) is a technique where you apply augmentations at inference time rather than (or in addition to) training time, and average the predictions."
>
> — albumentations TTA guide
