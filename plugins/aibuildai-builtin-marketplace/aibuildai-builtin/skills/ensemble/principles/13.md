# Principle 13: Bagging (Bootstrap Aggregating)

**Space**: Model-space / meta.

**Source**: Breiman 1996, *"Bagging Predictors"*; scikit-learn `BaggingClassifier`, `BaggingRegressor`.

## Definition

Draw **N bootstrap samples** from the training set — each sample is drawn with replacement and has the same size as the original — train N base learners independently on the resulting resamples, and combine their predictions by average (regression) or majority vote (classification).

## Mechanism

Each bootstrap sample contains ≈63.2% unique rows of the original training set; the remaining ≈36.8% are natural **out-of-bag (OOB)** samples that serve as a free validation set for that member. Base learners train in parallel with no coordination. Averaging the predictions reduces the variance of unstable base learners without substantially affecting their bias. Random Forest is the canonical realization: bagged decision trees with additional feature-level randomization.

## Pros

- **Reduces variance** of unstable base learners (decision trees, neural networks). Hall-of-fame technique for turning high-variance learners into robust ensembles.
- **Embarrassingly parallel** in both training and inference — every member is independent.
- Free OOB validation signal; no separate held-out set required.

## Cons

- **Does not reduce bias.** A systematically biased base learner stays biased after bagging.
- Can slightly hurt stable learners (linear regression, k-NN). Variance reduction is only valuable when variance is the dominant error term.
- N× inference cost.

## When to Use

When the base learner is unstable (decision trees especially) and the dataset is moderate-sized. Default to Random Forest for tabular tasks where a tree-based learner is appropriate and fast iteration on ensemble size is valuable. Less commonly used with deep neural networks because training N DNNs from scratch is expensive compared to cheaper DL ensemble methods like snapshot ensembling or K-fold.

## Common Misconception

That bagging and K-fold ensembling are the same. They are not. Bagging samples **with replacement** from the full training set (members see overlapping, noisy subsets that average 63% unique rows). K-fold partitions **without replacement** (members see disjoint-overlap, structured subsets of exactly (K−1)/K rows each). Bagging members are more decorrelated at equal count; K-fold members have deterministic shared rows.

## Load-Bearing Quote

> "Bagging leads to improvements for unstable procedures, which include artificial neural networks and classification and regression trees."
>
> — summary of Breiman 1996 in the scikit-learn Ensemble documentation
