# Principle 7: Anisotropic (Per-Axis) Scale

## Invariance it assumes

f(Scale_{sx, sy}(x)) = f(x) for independent horizontal and vertical scale factors. The task label is unchanged when the image is stretched along one axis but not the other.

## Mechanism

Resample the x-axis by sx and the y-axis by sy, with sx ≠ sy allowed. Typically drawn from the same range but independently, or one axis fixed while the other varies.

## When this invariance typically holds

- Tasks with **no calibrated per-axis scale** and no ratio-preserving label signal: natural images of amorphous textures.
- **Aspect-ratio-robust recognition** where real-world acquisitions introduce independent x / y rescaling: cameras with variable optical aspect.
- **Font-family-agnostic OCR** across condensed / stretched fonts — the text is still readable under moderate x/y stretching.
- **Generic abstract textures / patterns**.

## When this invariance breaks

- **Tasks with per-axis physical semantics**:
  - Sedimentary / stratigraphic cross-sections: horizontal = lateral distance, vertical = depth.
  - Time-series spectrograms: x = time, y = frequency — each axis has a distinct physical unit.
  - Bathymetric or ultrasound depth images.
- **Anatomy with fixed proportions**: face recognition (eye-separation / face-width ratio is diagnostic), cardiac imaging (chamber-size ratios), body-proportion measurements.
- **Calibrated scientific imaging** where each axis has a distinct physical unit.
- **Any task where the ratio of horizontal to vertical extent carries information**.

## Silent failure mode

Unlike flips, anisotropic stretch produces visually plausible images that the model will train on without error. The training distribution has corrupted per-axis priors; the test distribution has anatomically or physically correct proportions. The model's per-axis features become unreliable specifically on the inputs it will see at test.

## Safer fallback: axis-fixed anisotropic

If the per-axis semantics are unequal — horizontal is arbitrary but vertical encodes depth — a common safer pattern is to **vary only the horizontal factor**, leaving sy = 1. This preserves the depth axis and still exposes the model to lateral scale variation. Seen in practice in some seismic and spectrogram augmentation pipelines.

## Common misconception

"If isotropic scale is safe, anisotropic is also safe." Wrong in any domain where the two axes encode different physical quantities. Isotropic scale preserves per-axis ratios; anisotropic breaks them. These are two separate invariance checks.
