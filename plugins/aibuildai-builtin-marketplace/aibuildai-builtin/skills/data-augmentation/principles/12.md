# Principle 12: Local Histogram Equalization (CLAHE)

## Invariance it assumes

f(CLAHE(x)) = f(x). Predictions are unchanged when each local patch of the image has its contrast re-normalized to fill the full dynamic range. This encodes the claim that **local absolute amplitude has no task signal** — only structure relative to a local reference.

## Mechanism

Partition the image into small tiles (typical 8×8). For each tile, stretch its intensity histogram to cover the full range, with a clip limit preventing extreme stretching. Bilinear interpolation is used between tile centers to avoid tile-boundary artefacts.

## When this invariance typically holds

- **Medical imaging with variable detector gain**: chest X-ray across scanners — the task depends on relative structural patterns, and absolute pixel value varies between scanners anyway.
- **Dermoscopy, fundus photography**: illumination conditions vary, and local normalization improves lesion visibility.
- **Underwater or foggy photography**: strong global illumination gradients are normalized away, revealing subject content.
- **Low-contrast natural images** where the task depends on subtle local structure: night photography, backlit scenes.

## When this invariance breaks

- **Tasks where absolute pixel amplitude is the label signal**:
  - Seismic reflection amplitude (directly encodes subsurface impedance contrast).
  - Quantitative ultrasound (amplitude ≈ tissue reflectivity).
  - SAR radar reflectance (amplitude encodes backscatter coefficient).
  - Calibrated optical / thermal sensors where pixel values have physical units.
- **Tasks depending on global intensity relationships** across the image: "brighter region" classification.
- **Data that has already been physically calibrated upstream**: applying CLAHE throws away the calibration.
- **Tasks where local tiles happen to contain only one class**: CLAHE stretches those tiles to full range regardless of the tile's actual intensity, introducing tile-to-tile intensity discontinuities that the model then has to unlearn.

## Silent failure mode

CLAHE produces visually "enhanced" images that look better to a human. The aesthetic improvement is not aligned with the task if the task depends on the original amplitudes. The model trains on the enhanced distribution and is then tested on raw data, producing a silent distribution shift — loss during training looks normal, test performance drops.

## Interaction with normalization

CLAHE is applied **before** standard ImageNet normalization. If CLAHE is enabled, the normalization statistics (mean, std) should be recomputed on CLAHE-transformed data, or at minimum not assumed to match the raw-pixel statistics. Mixing CLAHE with stock ImageNet stats (mean=0.449, std=0.226 for grayscale) usually still works because CLAHE preserves approximate [0, 1] range, but it is a subtle source of drift.

## Common misconception

"CLAHE always helps because it improves contrast." It helps when the task does not rely on absolute amplitude. In domains where absolute amplitude is the signal, CLAHE actively destroys the signal.
