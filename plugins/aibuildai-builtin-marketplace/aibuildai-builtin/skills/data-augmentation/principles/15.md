# Principle 15: Cutout / Random Erasing / Coarse Dropout

## Invariance it assumes

f(Erase(x)) = f(x). The task is robust to occlusion — a random rectangular region of the input being zeroed (or filled with a constant / noise) should not change the label. This encodes the claim that **class evidence is sufficiently distributed across the image** that no small erased patch can destroy it.

## Mechanism

Randomly select a rectangular region (size and aspect-ratio drawn from a specified distribution) and set its pixels to a constant — zero, global mean, or Gaussian noise. Typically applied to a fraction of samples (p ≈ 0.1–0.5) with 1–3 holes per image. Variants: Cutout (single fixed-size hole), Random Erasing (random-size), CoarseDropout (multi-hole), GridMask (regular lattice of holes).

## When this invariance typically holds

- **Natural-scene classification** where the class is spatially distributed: landscapes, common objects photographed with context.
- **Robustness-focused applications**: outdoor perception with possible physical occluders (pedestrians, cars, foliage).
- **Face recognition with occlusion-robustness as a design goal** (masks, glasses, partial occlusion).
- **Fine-grained classification on whole images** where the discriminative region is at least a moderate fraction of the image.

## When this invariance breaks

- **Sparse-target tasks**: small-object detection, sparse-object segmentation where the target occupies a small fraction of the image. An erase rectangle placed on the target destroys the only label-bearing signal, creating a "label-present-but-evidence-gone" contradictory gradient.
- **Dense-prediction tasks with small objects**: medical micro-calcification, thin-vessel segmentation, small-boat detection in overhead imagery, crack detection.
- **Sparse-foreground segmentation with imbalanced classes**: when the foreground is already rare, erasing it makes it rarer.
- **Tasks whose label depends on a specific region**: medical localization labels tied to a single organ.

## Design check before enabling

Estimate: what is the probability that a randomly placed erase rectangle overlaps a target object of median size? A rough formula — if the mean target occupies fraction p_obj of the image and the erase rectangle occupies fraction p_erase, the collision probability is approximately p_obj + p_erase. If this exceeds some threshold (≈ 0.1) and target evidence is already sparse, cutout produces more false-negative gradients than useful regularization.

## Interaction with label semantics

For segmentation: the erased region is not relabeled as background — the mask under the erase is still the true mask. This means the loss is computed with "input says nothing, label says foreground." Many codebases handle this correctly (the erased region is masked out of the loss, or the label is also erased). Some do not. Before enabling for segmentation, verify which convention the loader uses.

## Common misconception

"Cutout is a universal regularizer." Cutout assumes redundancy of class evidence across the image. When evidence is concentrated in a small region — which is common in medical imaging and in sparse-foreground segmentation — cutout is a task-destroyer, not a regularizer. No top Kaggle solution on a sparse-foreground segmentation task (e.g., most salt / road / defect segmentation) has published a CoarseDropout config as part of its final pipeline.
