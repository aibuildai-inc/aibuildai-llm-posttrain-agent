# Principle 9: Elastic / Grid Deformation

## Invariance it assumes

f(Elastic(x)) = f(x) for smooth local diffeomorphisms of small magnitude. The task is locally invariant to small non-linear distortions of the input — mild local stretching, squeezing, wiggling — provided the spatial label is warped by the same displacement field.

## Mechanism

Displace each pixel by a smooth random vector field. Two common parameterizations:

- **Elastic (Simard et al. 2003)**: random Gaussian-blurred displacement field. `alpha` controls magnitude, `sigma` controls smoothness.
- **Grid distortion**: a coarse control-point grid (e.g. 5×5), each point perturbed within a range, interpolated between.

The spatial label (mask, keypoints) must be warped with the same field; the data loader must apply the transform to both input and label.

## When this invariance typically holds

- **Medical imaging with mild biological shape variation**: prostate, tumor-boundary shape, organ contour.
- **Microscopy / histology** where tissue deformation during slide preparation is realistic.
- **Handwriting recognition** — local stroke wobble is exactly what elastic was introduced for (original Simard 2003 paper on MNIST).
- **Natural-scene images with soft-deformable subjects**: fabric, hair, vegetation.
- **Cell segmentation** (the canonical U-Net elastic-augmentation use case).

## When this invariance breaks

- **Rigid-structure tasks**: architecture, industrial parts, barcode / QR-code reading, grid patterns, any man-made rigid object.
- **Rigid calibrated imaging**: quantitative measurement on images where geometry must be preserved.
- **Thin-structure segmentation**: fine vessels, cracks, 1-pixel-wide features. Elastic can disconnect or self-intersect thin structures, corrupting both input and label.
- **Text**: elastic at default strength makes letters unreadable.
- **Physics-constrained imaging**: seismic, sonar — elastic warps displace features in ways that violate the underlying wave-propagation geometry, potentially moving a reflector to a physically impossible location.

## Parameter sensitivity

Elastic has two interacting parameters (magnitude and smoothness). Wrong choices fail in opposite directions:

- Very large displacement + very smooth field → looks like a global warp (large translation + rotation), not a local elastic deformation.
- Very small displacement + very rough field → looks like high-frequency pixel noise, not a meaningful geometric deformation.

Both fail to be the intended "small local warp." Sensible defaults (albumentations): `alpha ≈ 1.0, sigma ≈ 50`; or grid-based with `grid=10, distort_limit ≤ 0.2`.

## Common misconception

"Elastic is a universal segmentation augmentation because it was introduced for cell segmentation." The original use case (cell segmentation) involved biologically-deformable structures on a 2D slide. Not every segmentation task has that property. Rigid, calibrated, or thin-structure tasks should not use elastic at default strength.
